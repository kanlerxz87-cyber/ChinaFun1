How to reproduce any price on this site

  1. Open the source URL in the register above — it already contains the date parameters, for example ?checkin=2027-03-08&checkout=2027-03-15&group_adults=2&no_rooms=1&sb_price_type=total&type=total&selected_currency=USD.
  2. Confirm the party is 2 adults, 1 room, and that the display is set to total price in USD.
  3. Read the room name and the “Price … 7 nights” figure, plus the included and excluded tax lines.
  4. Compare with the value published here and note the new fetch timestamp. Rates move; a difference is expected and is not an error in the earlier snapshot.

The same pattern works for the restaurant menus: the T'ang Court set-menu PDF and the Taian Table Menu No.55 PDF are permanent official URLs and can be re-opened to confirm every figure quoted from them.
